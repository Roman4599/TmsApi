# 🎓 TMS API – Training Management System

## 📝 What is this?

A production-grade RESTful API for managing students, courses, and enrollments. Built with **ASP.NET Core 10** following **Clean Architecture** principles.

This project demonstrates:
- ✅ Clean Architecture (4 layers)
- ✅ API Versioning with deprecation headers
- ✅ CQRS with MediatR
- ✅ Result pattern for business failures
- ✅ HybridCache with stampede protection
- ✅ Tier-aware rate limiting
- ✅ Background workers with idempotency
- ✅ SignalR real-time notifications
- ✅ RFC 7807 ProblemDetails error responses
